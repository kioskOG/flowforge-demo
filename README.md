# flowforge-demo

A small shop platform for trying [FlowForge](../FlowForge) hands-on:

- `services/orders-go`: Go API with a Dockerfile
- `services/pricing-py`: Python (uv) library
- `web/storefront`: Node app with a demo deploy script

There is no CI configuration here on purpose. FlowForge generates it. Follow [GUIDE.md](GUIDE.md).
